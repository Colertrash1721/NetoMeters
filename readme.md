# NetoMeters

Smart energy consumption monitoring and management platform.

> **Project status:** Frontend in development. Backend architecture and technology stack are still being evaluated.

## About

**NetoMeters** is a web application designed to provide intelligent monitoring of energy consumption through a modern and intuitive interface.

The project currently focuses on the frontend experience, with plans to integrate a backend and real-time data services in future development stages.

## Tech Stack

### Frontend

- [Next.js](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)

### Backend

> Not implemented yet. The backend technology and architecture are currently being evaluated.

## Current Features

- Modern and responsive user interface
- Energy consumption monitoring interface
- Dashboard-oriented design
- Responsive layouts
- Reusable UI components

## Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/netometers.git
cd netometers
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
